# 国网知识库 HTML 原型页面设计规则

更新时间：2026-10-21

本规范适用于国网物资公司大型知识库系统的所有 HTML 原型页面。所有页面生成与修改必须遵守。

## 1. 尺寸与布局

- 设计与验收基准宽度：`1440px`
- 最小适配宽度：`1280px`；在 1280px 及以上不出现页面横向滚动条
- 页面高度：不限制，以业务内容完整展示为准，不得使用固定页面高度裁切正文内容
- 经典布局：56px 全宽顶部栏覆盖侧边导航与内容区顶部；左侧导航栏默认以 220px 宽展开，所有系统页面均可拖拽右侧边缘拉宽至 420px，宽度在当前浏览器会话中跨页面保持，不支持整体收起；侧栏从顶部栏下方开始，不显示品牌区和分组标题；一级功能入口统一排列，业务目录节点按层级缩进并支持展开收起；父节点点击后进入首个直接子页面，当前路径父标题和图标使用主题色高亮；内容区内边距 24px
- 弹窗宽度：小型 480px、中型 640px、大型 800px
- 弹窗最大高度：视口高度的 85%，超出内容在弹窗内容区内部滚动
- 仅制作电脑端，不做手机端适配

## 2. 色彩

### 品牌色

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 主色 | `#1F827A` | 主按钮、链接、选中态、导航高亮 |
| 主色浅 | `#3BA39A` | 按钮 hover、图标 |
| 主色深 | `#156B64` | 按钮点击、强调文字 |
| 主色极浅 | `#EDF7F5` | 选中行背景、标签背景、输入框 focus |

全宽系统顶部栏高 56px，使用统一的纯色深青绿 `#10A69A`。左侧显示包含国家电网圆形图形、“国家电网公司 / STATE GRID”、横线及“国网物资有限公司 / State Grid Materials Co., Ltd”的完整透明底组合标识；之后使用白色竖线分隔，并直接显示“企业经营管理系统 / BOMP”两行文字，不再重复显示独立的国家电网圆形标志。中间导航依次为首页、管理看板、经营管理、知识共享、人工智能、供应链业务数据、系统管理，相对整个视口水平居中，默认用更深色背景高亮“人工智能”；右侧依次显示“退出登录”和“您好，孙鹏飞”。

### 中性色

| 用途 | 色值 |
|---|---|
| 标题文字 | `#1f1f1f` |
| 正文文字 | `#595959` |
| 次要/说明文字 | `#8c8c8c` |
| 边框 | `#d9d9d9` |
| 分割线 | `#f0f0f0` |
| 页面背景 | `#f5f5f5` |
| 卡片背景 | `#ffffff` |

### 语义色

- 成功：`#52c41a`
- 警告：`#faad14`
- 错误：`#ff4d4f`
- 语义色仅用于操作结果提示和状态标签，不参与品牌视觉

## 3. 字体

- 字体族：`PingFang SC`、`Microsoft YaHei` 等系统默认无衬线字体
- 基准字号：14px；基准行高：1.57
- 页面标题：20px / 600
- 卡片标题：16px / 600
- 正文：14px / 400
- 辅助说明：12px / 400

## 4. 基础组件

### 按钮

- 主按钮：国网绿底、白字、高 32px、圆角 2px
- 次按钮：白底、灰色边框
- 文字按钮：无背景、国网绿文字，用于行内操作
- 危险操作：红色文字按钮
- 相邻按钮间距：8px
- 所有原生按钮统一使用 2px 圆角，包括文字按钮、图标按钮、导航按钮和弹窗按钮

### 表单

- 标签左对齐、宽 100px
- 必填项标签前添加红色 `*`
- 输入框高 32px、圆角 6px，focus 时边框变为国网绿
- 底部按钮组右对齐，主按钮位于最右侧
- 筛选下拉框未选择具体条件时仅显示类别名称；选择后显示“类别：选中值”，并使用主题色边框、浅色背景和主题色文字表示激活。普通表单、知识库范围选择和分页条数下拉保持原有值显示

### 弹窗

- 白色背景、圆角 8px、带阴影
- 结构为标题栏、内容区和底部按钮区
- 点击遮罩或关闭图标均可关闭

### 标签

- 用于文档类型和分类
- 高 24px、圆角 4px、字号 12px
- 默认使用国网绿极浅背景和国网绿深色文字
- 不同分类可使用灰、蓝、橙等浅色背景区分，但同一页面不超过 4 种颜色
- “我的知识”状态标签统一采用浅色背景与对应深色文字：已发布为浅绿 `#E8F5EF` / 深绿 `#216B57`，待审核为浅黄橙 `#FFF3D9` / 深橙 `#945A0A`，私有草稿为浅灰 `#F0F2F2` / 深灰 `#596260`，协作分享为浅蓝 `#EAF2FC` / 深蓝 `#315F99`
- 状态色保持低饱和度，不与删除、下载等操作按钮争夺视觉优先级

## 5. 演示交互

所有演示必须实现：

1. 点击侧边栏可切换页面，当前页面使用国网绿高亮。
2. 所有按钮、链接和可点击行均有 hover 反馈。
3. 弹窗可以打开，并可通过遮罩或关闭图标关闭。
4. 表单提交后显示“操作成功”提示，2 秒后自动消失。
5. “列表 -> 详情 -> 返回”链路可以完整点击。
6. 带搜索框的页面输入内容后可以过滤列表，使用前端模拟即可。
7. 提供列表/宫格切换的页面默认选中列表视图；表格标题或名称列允许最多显示两行，两行仍放不下时使用省略号，并通过 `title` 提供完整文本；其他字段的标题和内容全部单行显示，放不下时使用省略号。
8. 全系统文件表格按信息优先级使用弹性列宽：名称或标题列使用 `auto` 自动吸收扣除其他字段后的剩余空间，不设置固定像素或固定百分比；复选框、类型、大小、人员、时间、状态、目录和操作等字段按内容长度使用百分比权重随容器伸缩。所有列使用一致的横向内边距和稳定行高，操作列必须完整显示全部按钮，不得在仍有明显空白时挤压或截断相邻字段，也不得人为强制短表头换行。
9. 部门知识库左侧目录直接驱动右侧文件列表；一级目录聚合其全部下级文件，二级目录仅展示自身范围，并同步显示当前目录、完整层级和文件数量。
10. “审核工作台”承接原审核工作台内容；待审核记录提供单条和批量审核操作，已处理记录不重复显示审核按钮；审核筛选仅保留状态筛选和关键词搜索，不提供提交日期筛选；申请详情使用 480px 右侧抽屉，入库位置放在知识基本信息之前并展示两条目标目录示例，抽屉内容独立滚动且底部审核操作保持可见。审核页不显示重复的“审核工作台 > 审核工作台”面包屑；表格在提交人后展示共享目标（固定显示“公司知识库”）和所属部门，操作列固定在列表最右侧并右对齐。侧边导航将其作为独立一级入口。
11. 侧边导航箭头只负责展开收起，目录文字负责选中或跳转；展开收起局部更新并保持当前滚动位置，部门和公司知识库内部目录切换不整页刷新。一级导航图标为 18px，带图标的子项为 14px，展开箭头为 13px。
12. “知识库管理”一级导航仅下设部门知识库管理、公司知识库管理两个直接子页面，依次排列。专业目录管理页面保留兼容地址但不作为公共侧边导航子项；可见页面独立高亮，父节点文字进入首个子页面；点击部门知识库或公司知识库父入口时仅展开直接子级，不自动展开第二级目录。
13. 部门知识库管理内部使用知识统计、知识管理、目录管理、上传任务、共享管理、回收站、管理日志七个水平页签。统计图表必须提供明确标题、图例和文字替代，不以颜色作为唯一信息；知识列表的批量操作仅在选中记录后启用；目录树的展开与选择动作分离；删除类操作使用 480px 确认弹窗。
14. 部门知识库管理的知识分布以“供应链运营中心”的全部一级目录为唯一统计口径，每页最多展示 6 个目录，并提供可禁用的上一页、下一页按钮与当前页码；知识排行榜提供引用次数、下载次数、收藏次数和 AI 引用次数四种排序；知识使用情况使用开始日期、结束日期和日历图标组成的日期范围控件，并校验开始日期不晚于结束日期。部门目录管理页不显示目录搜索框和“使用中”标签。
15. 公司知识库专业目录管理使用知识统计、知识管理、目录管理、回收站、管理日志五页签；公司知识库管理使用知识统计、知识管理、目录管理、上传任务、共享管理、回收站、管理日志七页签，并在页签右侧提供上传知识入口。两套统计页的知识分布和知识使用情况均采用上下全宽布局，专业统计按专业一级目录、公司统计按部门一级目录分页展示且保留各自原数据；两者的知识排行榜均支持访问、收藏、下载和 AI 引用次数排序。专业和公司目录管理页均不显示目录搜索框和“使用中”标签。公司知识管理文件夹列表的操作内容固定右对齐到表格末端，关键词搜索图标嵌入搜索框右端。我的上传状态切换使用向左集中的横向等宽标签栏，标签间以细分隔线区分，当前项使用主题色文字和底部短指示线；我的上传列表不显示“智能处理结果”字段，公司知识库管理的上传任务仍保留该字段；我的上传名称列自动吸收剩余空间，文件大小、上传时间、当前状态和操作列按 10%、15%、13%、22% 分配权重。
16. 专业目录管理的目录树按供应链运营中心部门级知识目录样例逐级展示，根节点固定为“供应链运营中心”；目录节点来源为一级目录、二级目录和各级文件夹，空值及 `/` 跳过，知识文件只用于汇总当前节点及全部下级节点的知识数量。所有有子级的目录初始默认展开以展示完整知识层级；展开箭头只控制当前节点的直接子级，目录文字负责选中并同步右侧名称、完整路径、上级目录、知识数量和说明；长名称单行省略并提供完整标题提示。
16. 部门知识统计首页顶部使用部门知识总量、本月新增、AI 引用次数三个等宽数据卡片，卡片间距一致且总宽与下方模块对齐；下方知识分布和知识使用情况采用上下全宽布局。知识分布使用垂直窄条形图，横轴一屏展示全部 14 个一级目录、柱顶显示知识篇数；知识使用情况保留四指标折线图，时间预设和日期范围控件放在模块标题栏右侧。
17. 搜知识页面的 AI 速读采用按需右侧栏，初始列表全宽；点击某条文件的“AI速读”后显示与该文件绑定的摘要，并可收起。AI 问答、搜知识和搜图片的顶部“历史记录”打开同一公共历史面板，面板提供收起操作；历史记录与 AI 速读互斥显示，`Escape` 可关闭并恢复触发按钮焦点。
18. AI 智能问答的输入区提供“添加文件”“添加图片”入口和已选附件移除能力；问题区应展示本轮附件。长回答放在独立可滚动区域，回答中的引用角标与右侧相关文件编号一一对应并支持点击定位。相关引用栏与其他检索侧栏统一为 340px，在 1280px 视口下统一为 300px；无权限文件仅展示最小必要元数据和“申请权限”，回答末尾明确提示用户可发起访问权限申请。
公共侧边导航不展示个人中心入口，个人中心相关页面保留兼容地址；审核工作台位于公司知识库之后、知识库管理之前，作为独立一级入口。我的知识库固定承载最近使用、我的知识、我的协作、我的收藏、我的上传、我的共享和回收站；“我的共享”展示本人发起的共享提报与审核进度，审核工作台展示需要当前用户处理的审核任务。我的信息、我的浏览和我的下载保留兼容页面地址但不出现在公共侧边导航。我的上传和审核工作台不显示顶栏搜索，内容区搜索继续保留。
20. 知识共享中心首页不展示高级搜索入口，保留知识库范围、附件、图片和发送能力。“搜知识”页面的高级搜索使用 800px 弹窗按需展开，固定提供关键词、上传日期范围、上传部门、文件归属部门、类型和公开范围。所有非空条件必须按 AND 关系精确匹配；日期范围校验开始日期不晚于结束日期，至少设置一个条件后才执行。结果页显示命中数量和条件标签，列表展示上传部门、文件归属部门、完整上传时间及原文件操作，并提供修改条件和清空条件入口。搜索条件只使用会话级存储。
21. “我的知识库 > 最近使用”批量工具栏依次展示下载、共享提报和删除。共享提报使用原生禁用态，未选中记录时不可操作；勾选一条或多条记录后启用。每条文件的“更多”菜单在创建副本之后、权限管理之前提供单条共享提报。两类入口共用 640px 弹窗，展示已选文件并依次提供共享目标、至少选择一个且可多选的目标目录、可见范围和最多 300 字的选填共享说明；目录选项使用复选框，已选结果以显示末级名称的可移除标签换行展示并通过 `title` 保留完整路径。部门与公司目录分别递归读取公共侧边导航的 `window.BompDepartmentDirectoryData` 和 `window.BompCompanyDirectoryData` 全部节点，选择面板提供名称或完整路径搜索及结果数量。部门和公司目标切换时清空并替换目录与默认可见范围，选择指定可见时再展开对象搜索。提交、取消、遮罩和 `Escape` 关闭均保持明确焦点反馈，成功后显示 2 秒提示。
22. 公共侧边导航中的部门知识库目录与专业目录管理页使用 `知识目录/部门级、公司级文件共享层级示例_供应链运营中心 .xlsx` “部门知识库样例”的同一份目录数据，按 B-E 列完整保留 14 个一级目录及多级层次，F 列知识文件不生成目录节点。侧栏进入部门知识库时只展开当前选中目录所在路径，其他分支保持收起；第 4 至第 6 层继续递增缩进，长名称单行省略并保留 `title`，不得挤压展开箭头或造成侧栏横向滚动。
23. 公共侧边导航中的公司知识库目录与“公司知识库管理 > 目录管理”使用 `知识目录/公司级.xlsx` “公司知识库目录层级”的同一份数据，按 B-G 列完整展示 11 个一级目录及全部文件夹层级，H 列知识资料内容不生成目录节点。侧栏与目录管理不得各自硬编码不同的公司目录；长名称与展开交互继续遵循公共侧栏规范。
24. 部门知识库和公司知识库文件列表页使用目录信息型顶部栏：左侧展示“当前目录”、目录名称、完整层级、范围说明和文件数量，右侧展示搜索框；不再显示重复的“知识库 > 当前目录”面包屑，内容区也不重复目录摘要。长目录名称与层级单行省略并提供完整悬停提示，在 1280px 及以上不得挤压搜索框或产生横向滚动。列表“文件位置”列仅展示末级目录名称，完整目录层级通过该文本的 `title` 供悬停查看。
25. “我的共享”表格使用全局弹性列宽，名称列自动吸收剩余空间，目标目录、提交时间及其他短字段按内容长度配置比例权重。名称列最多两行并保留完整提示，其余字段单行省略；1280px 至 1920px 下各列应随表格等比例伸缩，不出现名称列独占大面积空白或短字段相互挤压，提交时间和操作需完整显示。
26. 共享提报弹窗的目录多选使用逐条添加结构：默认一条 36px 高目录选择框，其下提供无边框主题色“增加目录”操作；新增选择框右侧提供独立删除按钮。目录下拉面板包含搜索框和层级列表，节点按层级递增缩进，每个层级均可选择，节点同时展示当前名称与完整路径；已选节点高亮并禁止在其他行重复添加。长路径在选择框内单行省略并通过 `title` 保留完整内容，弹窗在 1280px 及以上不得横向溢出。

不实现真实接口、复杂校验、权限和数据持久化。

## 6. 示例数据

所有列表和详情页使用知识库文档风格的数据。禁止出现 `test`、`aaa`、`Lorem ipsum` 等占位内容。

### 文档标题示例

1. 《国网物资公司-2025年企业经营管理系统-设计开发实施项目业务需求说明书》
2. 国网物资公司-2025年企业经营管理系统-设计开发实施项目软件需求说明书
