# 侧边导航

组件 ID：`app-sidebar`

使用 `<bomp-sidebar>` 渲染知识共享中心目录导航。`active` 指定当前节点。

```html
<bomp-sidebar active="company-library"></bomp-sidebar>
```

组件位于 56px 全宽顶部栏下方，不显示独立 Logo、“知识共享中心”文字或分组标题。一级功能入口统一排列，含子项的节点可按业务目录完整层级逐级展开；长目录名称省略显示，并通过 `title` 查看全文。

一级功能入口默认显示图标；当前页面所在路径的父级标题与图标使用主题色高亮，当前叶子节点同时显示浅色选中背景。目录圆点默认隐藏，需要显示时可添加 `show-icons` 属性：

```html
<bomp-sidebar active="company-library" show-icons></bomp-sidebar>
```

侧栏默认以 220px 宽展开，所有引用该公共组件的系统页面都可拖拽右侧边缘拉宽至 420px；边缘中部使用细竖条提示可拖拽区域。双击边缘恢复 220px，聚焦边缘后也可用左右方向键按 20px 调整。宽度在当前浏览器会话中跨页面保持，不提供整体收起按钮。目录节点自身仍可通过右侧箭头逐级展开或收起。

默认菜单依次为：首页、我的知识库、部门知识库、公司知识库、审核工作台、知识库管理、标签管理、系统管理。个人中心页面保留兼容地址但不作为公共侧边导航入口。标签管理入口进入 `pages/prototype-suite/tag-management.html`，新增标签提交系统管理员审批；停用保留历史关联，删除仅允许关联知识为 0 的标签。

- 我的知识库：最近使用、我的知识、我的协作、我的收藏、我的上传、我的共享、回收站。
- 个人中心：保留个人中心相关兼容页面地址，但不作为公共侧边导航入口。审核工作台作为独立一级入口承接审核任务；我的信息、我的浏览和我的下载保留兼容页面地址但不再出现在公共侧边导航；“我的共享”展示本人发起的共享进度。
- 部门知识库：与“专业目录管理 > 目录管理”共用 `window.BompDepartmentDirectoryData`，数据来源为 `知识目录/部门级、公司级文件共享层级示例_供应链运营中心 .xlsx` 的“部门知识库样例”；B-E 列形成架构管理、数字化需求管理等 14 个一级目录及全部下级层级，F 列知识文件仅汇总数量，不生成导航节点。
- 公司知识库：与“公司知识库管理 > 目录管理”共用 `window.BompCompanyDirectoryData`，数据来源为 `知识目录/公司级.xlsx` 的“公司知识库目录层级”；B-G 列形成 11 个一级目录及全部下级层级，H 列知识资料内容不作为目录节点。
- 知识库管理：部门知识库管理、公司知识库管理。专业目录管理页面保留兼容地址，但不再作为公共侧边导航子项。
- 点击“部门知识库”或“公司知识库”父入口时，只展开其直接子级并选中第一个一级目录，不自动展开该目录的下级；展开箭头仍只控制当前节点。

目录文字与展开箭头使用独立交互：点击箭头仅局部展开或收起目录并保留滚动位置；点击普通父节点文字后进入第一个直接子节点，例如“我的知识库”进入“最近使用”，“部门知识库”进入“架构管理”。部门知识库和公司知识库中的一级目录是可选择的聚合节点，点击文字后选中自身并展示其全部下级文件；下级目录点击后仅展示自身范围。进入部门知识库时只自动展开当前选中路径，其他分支保持收起。其他叶子节点点击后直接触发 `navigation-change`。上下方向键可切换可见节点，右方向键展开，左方向键收起或返回父节点。自定义菜单可通过元素的 `sections` 属性传入，数据结构支持递归 `children`。

组件内所有导航按钮统一使用 2px 圆角，与项目全局按钮规范一致。

图标尺寸统一为：一级入口 18px、带图标的子项 14px、展开箭头 13px。图标视觉缩小但保留原有按钮点击区域。
