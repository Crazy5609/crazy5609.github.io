# BOMP 原型 Demo

本目录用于建设并演示 BOMP 大型 B 端项目的 HTML 原型。

## 项目入口

- 项目背景与角色权限：`docs/project-background.md`
- 项目执行规则：`docs/project-rules.md`
- 原型页面规范：`docs/prototype-guidelines.md`
- 组件库维护规范：`components/README.md`
- 组件登记表：`components/registry.json`
- 决策与待确认记录：`docs/decision-log.md`
- 本地运行环境：`scripts/use-local-env.ps1`
- 原始需求资料：`BOMP知识共享中心软件需求说明书.docx`
- 最小功能单元表：`知识共享中心-最小单元功能表.xlsx`

项目处于原型建设阶段，已建立项目背景、执行规则、国网知识库原型规范、公共组件库和本地存储边界。后续页面应基于统一背景和公共组件逐步建设。
