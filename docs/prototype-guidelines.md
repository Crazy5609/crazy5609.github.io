# 国网知识库 HTML 原型页面设计规则

更新时间：2026-09-03

本规范适用于国网物资公司大型知识库系统的所有 HTML 原型页面。所有页面生成与修改必须遵守。

## 1. 尺寸与布局

- 设计与验收基准宽度：`1440px`
- 最小适配宽度：`1280px`；在 1280px 及以上不出现页面横向滚动条
- 页面高度：不限制，以业务内容完整展示为准，不得使用固定页面高度裁切正文内容
- 经典布局：220px 可折叠左侧导航栏 + 56px 顶部栏 + 内容区 24px 内边距
- 弹窗宽度：小型 480px、中型 640px、大型 800px
- 弹窗最大高度：视口高度的 85%，超出内容在弹窗内容区内部滚动
- 仅制作电脑端，不做手机端适配

## 2. 色彩

### 品牌色

| 用途 | 色值 | 使用位置 |
|---|---|---|
| 主色 | `#1F827A` | 主按钮、链接、选中态、导航高亮 |
| 主色浅 | `#3BA39A` | 按钮 hover、图标 |
| 主色深 | `#156B64` | 按钮点击、强调文字 |
| 主色极浅 | `#EDF7F5` | 选中行背景、标签背景、输入框 focus |

### 中性色

| 用途 | 色值 |
|---|---|
| 标题文字 | `#1f1f1f` |
| 正文文字 | `#595959` |
| 次要/说明文字 | `#8c8c8c` |
| 边框 | `#d9d9d9` |
| 分割线 | `#f0f0f0` |
| 页面背景 | `#f5f5f5` |
| 卡片背景 | `#ffffff` |

### 语义色

- 成功：`#52c41a`
- 警告：`#faad14`
- 错误：`#ff4d4f`
- 语义色仅用于操作结果提示和状态标签，不参与品牌视觉

## 3. 字体

- 字体族：`PingFang SC`、`Microsoft YaHei` 等系统默认无衬线字体
- 基准字号：14px；基准行高：1.57
- 页面标题：20px / 600
- 卡片标题：16px / 600
- 正文：14px / 400
- 辅助说明：12px / 400

## 4. 基础组件

### 按钮

- 主按钮：国网绿底、白字、高 32px、圆角 6px
- 次按钮：白底、灰色边框
- 文字按钮：无背景、国网绿文字，用于行内操作
- 危险操作：红色文字按钮
- 相邻按钮间距：8px

### 表单

- 标签左对齐、宽 100px
- 必填项标签前添加红色 `*`
- 输入框高 32px、圆角 6px，focus 时边框变为国网绿
- 底部按钮组右对齐，主按钮位于最右侧

### 弹窗

- 白色背景、圆角 8px、带阴影
- 结构为标题栏、内容区和底部按钮区
- 点击遮罩或关闭图标均可关闭

### 标签

- 用于文档类型和分类
- 高 24px、圆角 4px、字号 12px
- 默认使用国网绿极浅背景和国网绿深色文字
- 不同分类可使用灰、蓝、橙等浅色背景区分，但同一页面不超过 4 种颜色

## 5. 演示交互

所有演示必须实现：

1. 点击侧边栏可切换页面，当前页面使用国网绿高亮。
2. 所有按钮、链接和可点击行均有 hover 反馈。
3. 弹窗可以打开，并可通过遮罩或关闭图标关闭。
4. 表单提交后显示“操作成功”提示，2 秒后自动消失。
5. “列表 -> 详情 -> 返回”链路可以完整点击。
6. 带搜索框的页面输入内容后可以过滤列表，使用前端模拟即可。

不实现真实接口、复杂校验、权限和数据持久化。

## 7. 技术与复用

- 使用纯 HTML、CSS 和原生 JavaScript
- 所有页面引用 `components/base.css`
- 公共结构、样式和行为优先使用 `components` 中登记的组件
- 页面不得复制公共样式形成独立版本
- 页面使用的组件必须登记到 `components/registry.json` 的 `usedBy` 列表
- 页面专属样式必须限制在页面作用域内，避免污染公共组件

## 8. 页面生成检查清单

每次生成或修改页面前，按以下约束执行：

```text
这是国网物资公司的知识库系统原型，遵循以下规则：
1. 布局：设计基准1440px，侧边栏220px + 顶栏56px + 内容区24px；最小适配1280px，无横向滚动
2. 色彩：主色#1F827A，hover #3BA39A，深色#156B64，浅底#EDF7F5；文字#1f1f1f/#595959，页面背景#f5f5f5，卡片白底
3. 尺寸：基准字号14px，按钮和输入框高32px、圆角6px
4. 交互：实现导航高亮、按钮hover、弹窗开关、提交成功提示、列表到详情再返回和搜索过滤
5. 数据：使用真实感的知识库文档数据，长标题、文档编号、分类、上传人、时间、大小、版本；列表至少8条，禁止test、aaa和Lorem ipsum
6. 技术：纯HTML、CSS和原生JavaScript，统一引用components/base.css，不重复定义公共样式
```

## 9. 页面验收

- 在 1440px 视口下检查完整视觉与交互
- 在 1280px 视口下检查不出现横向滚动条
- 检查所有业务内容完整可见，页面高度能够自然增长
- 检查所有要求的交互链路能够点击完成
- 检查组件引用已登记，且未重复定义公共样式
- 检查示例数据数量、类型分布和业务真实性
