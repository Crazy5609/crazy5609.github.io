# 知识文件表格

组件 ID：`knowledge-table`

用于公司知识库、部门知识库、个人知识库等文件列表。默认包含 8 条知识库风格数据，也可以通过元素的 `rows` 属性传入页面数据。

```html
<bomp-knowledge-table id="knowledgeTable"></bomp-knowledge-table>
```

调用 `filter(query)` 可执行前端过滤并高亮标题中的命中词。点击文件名或双击普通行触发 `row-open` 事件；预览、下载、AI 速读和更多按钮统一触发 `table-action` 事件。

传入行数据时可设置 `restricted: true` 表示受限知识。组件将隐藏非必要信息和普通操作，只显示权限受限标识与“申请权限”入口，并触发 `table-action` 的 `apply-permission` 动作。

组件内文件名和操作按钮统一使用 2px 圆角，与项目全局按钮规范一致。列宽使用语义 `colgroup`：复选框与名称固定在左端，名称单行省略并自动吸收剩余空间；类型、范围、目录和时间按内容长度使用百分比权重；预览、下载、AI 速读和更多操作合并在最右侧操作列，统一右对齐并距表格右端保留 28px。列表外框不显示左右垂直边框，仅保留横向分隔线。
